# Supported Models

LMCache-Ascend currently supports the following models. All of them run
in **in-process mode**. Check out the listed branch before building.

| Model | Supported | Branch | Mode |
|---|---|---|---|
| GLM-4.7 | Yes | `main` | In-process |
| GLM-5 | Yes | `main` | In-process |
| GLM-5.1 | Yes | `main` | In-process |
| GLM-5.2 | Yes | `main` | In-process |
| GLM-5.3 | Yes | `main` | In-process |
| MiniMax-M2.7 | Yes | `main` | In-process |
| MiniMax-M3 | Yes | `main` | In-process |
| DeepSeek-V4-Flash | Yes | `dsv4_support_045` | In-process |
| DeepSeek-V4-Pro | Yes | `dsv4_support_045` | In-process |
